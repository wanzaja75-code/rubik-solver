Cara Menggunakan

1. Input Manual

Pilih warna dari color picker, lalu klik setiap sticker pada grid 2D untuk mengisi warna. Pastikan warna center sesuai dengan orientasi standar (Putih atas, Kuning bawah, Hijau depan, Biru belakang, Merah kanan, Oranye kiri).

2. Scan Rubik

Gunakan kamera atau upload foto untuk setiap sisi. Sistem akan mencoba mendeteksi warna, tetapi Anda selalu bisa mengoreksi hasilnya secara manual.

3. Mencari Solusi

Setelah semua 54 sticker terisi dan valid, klik "Cari Solusi". Algoritma solver akan menghitung langkah penyelesaian yang benar.

4. Menyelesaikan

Gunakan mode otomatis (Play) atau manual (Lakukan Langkah) untuk menyelesaikan Rubik. Rubik 3D akan menunjukkan layer mana yang diputar.

5. Acak & Selesaikan Otomatis

Klik tombol "⚡ Acak & Selesaikan Otomatis" untuk mengacak Rubik secara random, kemudian solver akan langsung menyelesaikannya secara otomatis dengan animasi.

Notasi Rubik

  • B = Belakang (Back)
  • ' = berlawanan jarum jam
  • 2 = 180°
